1. Who operates this tool

Skynet Uploader is a personal, single-user command-line tool operated by Kenn Bosak, an individual creator based in Blackwood, New Jersey, USA ("the operator"). The tool runs locally on the operator's own computer and is used only by the operator, only with the operator's own Google account. It is not offered to, or used by, any other person. Contact: kennbosak@gmail.com.

2. Data the tool accesses

With the operator's explicit OAuth consent, the tool accesses only the following, through Google's official APIs:

  • YouTube Data API v3 — upload scope (youtube.upload): used to upload video files, titles, descriptions, and custom thumbnails that the operator himself supplies, to the operator's own YouTube channel (youtube.com/@kennbosak).
  • Google Drive API — read-only scope (drive.readonly): used only when the operator selects a video file stored in his own Google Drive, so the tool can read that file and upload it to YouTube as described above. The tool never edits, moves, or deletes Drive files.

The tool does not access Gmail, contacts, calendars, location, or any other Google service, and it does not collect data about any person other than the operator.

3. How data is used

Data accessed through the APIs is used for exactly one purpose: carrying out the operator's own uploads to his own YouTube channel. The tool performs no analytics, no profiling, no advertising functions, and no automated decision-making about any person.

4. Storage and retention

  • OAuth access and refresh tokens are stored only on the operator's own computer, in a configuration folder restricted to the operator's user account by operating-system file permissions.
  • The tool does not store, cache, or retain any data returned by the YouTube or Google Drive APIs. The only records kept are the operator's own local publishing log (video IDs and public URLs of his own uploads) and the video files he created himself.
  • Video files read from Drive are held only transiently in memory/local temporary storage for the duration of an upload and are not copied to any third-party location.

5. Sharing

No data accessed through Google APIs is sold, rented, shared, or disclosed to any third party, for any purpose. There are no third-party processors, because the tool runs entirely on the operator's own machine.

6. Limited Use disclosure

Skynet Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide and improve the user-facing function described in this policy — uploading the operator's own videos to his own YouTube channel — and for no other purpose.

7. Google's privacy policy

Your use of Google services in connection with this tool is also governed by the Google Privacy Policy.

8. Revoking access and deleting local data

The operator (the tool's only user) may revoke the tool's access at any time at myaccount.google.com/permissions by removing "Skynet Uploader" from the list of third-party apps with account access. Revocation takes effect immediately with Google. To erase all local data held by the tool, the operator deletes the tool's local configuration folder, which removes the stored OAuth tokens; without those tokens the tool cannot access the account at all.
